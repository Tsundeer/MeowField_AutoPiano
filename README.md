# MeowField_AutoPiano 使用说明书

版本 **2.2.28**。

左侧边栏八个入口：播放、曲库、在线曲库、定时任务、音频转谱、键位与预设、设置、日志与诊断。右上角三个按钮分别是主题切换、语言切换（中 / EN）、设置。

---

## 1. 安装与启动

1. 系统需要 Windows 10 / 11 的 64 位版本。
2. 到 GitHub Releases 下载 `MeowField_AutoPiano-*-win-x64-Setup.exe`，地址在 <https://github.com/Tsundeer/MeowField_AutoPiano/releases>。
3. 双击安装，按提示完成。安装包自包含，不用另装 .NET、Python 或 Node.js。
4. 程序启动时会自动请求管理员权限（弹出 UAC 授权框）；若取消授权，则按普通权限运行，部分游戏窗口收按键可能不稳。

---

## 2. 载入曲子

进入「播放」页，三种方式：

- 点「打开 MIDI」，在文件框里选 `.mid` / `.midi`。
- 直接把 `.mid` / `.midi` 文件拖进窗口。
- 启动程序时带上 MIDI 文件路径，会自动载入。

载入后窗口标题下方显示文件名和完整路径，未载入时显示「尚未载入 MIDI / 请选择文件，或将 MIDI 拖入窗口」。

---

## 3. 绑定游戏窗口

1. 打开《开放空间》PC 端并进入乐器演奏界面。
2. 在右侧「播放参数」面板找到「目标窗口」，下拉框列出当前可见的窗口（格式为「进程名 - 窗口标题」）。
3. 若列表里没有想要的窗口，点「刷新窗口」按钮重新枚举，状态会变成「已发现 N 个窗口」；找不到时显示「未找到可绑定窗口」。
4. 选好目标窗口即可，顶部状态会从「未绑定目标窗口」变为已绑定。

> 「窗口消息（后台）」模式必须先绑定窗口，否则会提示「窗口消息模式需要先绑定目标窗口」。「前台模拟按键」模式会尝试把游戏提到前台，提不上去时会让您先点一下游戏再按快捷键。

---

## 4. 播放参数

右侧「播放参数」面板每一项都能当场调，改动立即对当前曲目生效。下面说明调了之后会怎样，并给几个例子。

- **输入方式**：「前台模拟按键」模拟真人前台按键，稳，但游戏得在前台；「窗口消息（后台）」走后台消息，适合支持该模式的游戏，不占前台也能弹。默认是窗口消息（后台）。

- **乐器 / 档案**：下拉里先列三种通用选项「钢琴（通用）」「架子鼓（通用）」「麦克风（通用）」，下面跟着游戏档案：
  - 开放空间 - 钢琴 / 架子鼓 / 麦克风
  - 异环 - 钢琴（固定半音）
  - 第五人格 - 钢琴（36 键）/ 竖琴 / 长笛
  
  选一个档案会一次性套用对应的键位、音域和演奏参数。默认是钢琴（通用）。

- **和弦处理**：「关闭」「优先和弦」「优先旋律」「智能识别」。选「优先旋律」时多个音同时来只保主旋律音；「优先和弦」尽量把和弦都弹全。默认优先和弦。

- **冲突处理**：音符太多、键位打架时的兜底办法，三种：
  - 原版折叠：尽量保留原曲音高关系，少改动。
  - 智能八度折叠：把超出乐器音域的音整体抬高或压低若干八度，落回能弹区间。
  - 逐音符最小移位：对每个冲突音做最小幅度挪动避让，尽量留住旋律走向。
  
  默认原版折叠。例子：一首音域很宽的曲子用原版折叠时高音弹不出、留白多；换智能八度折叠后高音整体降八度补齐，旋律连贯了，但整体音色偏低。

- **速度**：滑动条，范围 0.25 倍到 3 倍，步进 0.05，显示如「1.00x」。这是倍率，不是 BPM。调大整首弹得更快更紧，调小更舒缓。
  例子：原速 1.00x 觉得太赶，拖到 0.75x 旋律放慢四分之一，更易跟手；拖到 2.00x 则快一倍，适合踩点密的曲子。

- **转调**：滑动条，范围负 24 到正 24 半音，显示如「+12 半音」。正数升调、负数降调。
  例子：某曲最高音到 C6，而当前钢琴最高只到 C5，把转调压到负 12（降一个八度），整首降下来就能完整弹。

- **最大复音**：滑动条 1 到 21，默认 10。同时能按下的键数上限。调大厚和弦能完整弹出、更丰满；调得超过乐器或电脑承受力会丢音或卡。
  例子：弹和弦密集的曲子老丢音，从 10 提到 16，原本消失的内音出来了；提到 21 后开始卡，说明到硬件上限。

- **链路补偿**：滑动条负 500 到正 500 毫秒，步进 5，默认 0。补偿软件发键到游戏响应之间的延迟，让多音对齐更准。
  例子：连弹和弦总觉得「慢半拍」、音黏在一起，把补偿从 0 加到 30ms，多音对齐变干净。

- **音域下限 / 音域上限**：滑动条 0 到 127，默认下限 48、上限 83。限定乐器能弹的音高范围，超出部分按冲突处理或自动移调处理。

- **适配率**：只读文字，显示有多少音符落在当前音域内，并给出「原始 x%」的对照。数值越低说明曲子和乐器音域越不匹配，该考虑转调或换档案。

- **优先映射最近白键**：开关，默认开。黑键在乐器上缺失时，自动映射到最近的白键。下面的「最近白键方向」选「向上映射」或「向下映射」（默认向下映射）决定偏哪个方向。

- **载入时自动移调**：开关，默认开。打开后，载入曲子时按所选乐器音域自动把曲子移调到位，不用手拖转调滑条。

建议先用默认参数跑通一首简单曲子，再针对「弹不全」「节奏散」「声音太尖或太沉」去微调，比一次性全改省力。

## 5. 开始弹奏与播放队列

1. 载入曲子、绑定窗口、选好乐器和参数。
2. 点底部「播放」（播放中会变成「暂停」），或按快捷键。底栏还有「停止」、可拖动的进度条、已播 / 总时长。

播放队列在主窗口右缘的抽屉里：点底部播放条最右侧的队列按钮（带曲目计数角标）展开 / 收起，抽屉与主窗口同高，会跟随主窗口移动、最小化和被其他窗口遮挡。

- 「播放模式」四种：顺序播放（放完即停）、列表循环（放完回到第一首）、单曲循环、随机播放。一首放完按所选模式自动接续。
- 队列是全局的：从本地曲库、在线曲库、音频转谱或直接打开的曲目都会进入同一份队列，上一首 / 下一首、双击播放、上移 / 下移 / 移出 / 清空都在抽屉里操作。
- 队列会自动保存，下次启动还在。

---

## 6. 本地曲库

进入「曲库」页：

- 「添加文件」多选 MIDI 加入；「扫描目录」选一个文件夹批量收录。原文件不会被自动删除。
- 搜索框按曲名或目录筛，旁边可选文件夹过滤，「取消扫描」中止扫描。
- 列表列：曲名、目录、时长、音符、路径。每行可「载入」「加入队列」「移出曲库」（只从库里去掉，不动原文件）或「删除原文件」（永久删，会弹确认）。
- 底部「上一页 / 下一页」翻页，状态显示「共 N 首」。

---

## 7. 在线曲库

进入「在线曲库」页：

- 「刷新曲库」拉取最新曲目索引。
- 搜索框按曲名、分类或大小筛，点「搜索」；分类下拉含全部分类、游戏音乐、动漫与 ACG、虚拟歌手、古典与轻音乐、鼓组与节奏、华语与亚洲流行、欧美与其他、未分类；大小下拉含全部大小、小于 1 MB、1–5 MB、5–10 MB、大于 10 MB；排序下拉含默认顺序、名称 A→Z、名称 Z→A、大小小→大、大小大→小。
- 列表列：曲名、分类、大小，以及收藏（星标）和下载两个操作按钮。星标过的曲目会保存，勾选「只看收藏」可只看收藏；点「下载到本地」选好保存位置即可把曲目存为本地 MIDI 文件，并自动加入本地曲库的「在线下载」分组。
- 点「加载播放」下载并直接载入播放；下载内容会缓存在本地，在线曲目同样能进入播放队列。
- 曲库索引走国内可访问的镜像，GitHub 仅作备用源；索引会缓存在本地，再次进入页面直接读缓存，只有点「刷新曲库」才重新联网。镜像全部连不上时会沿用上次的列表，状态栏标注「离线缓存」。

---

## 8. 音频转谱

进入「音频转谱」页，调用本机 PianoTrans 把音频转成 MIDI：

1. 若没自动找到 PianoTrans，点「选择目录」指定本机 PianoTrans 所在文件夹（程序也会去常见位置找，找不到时状态显示「未找到 PianoTrans.exe」）。
2. 「输入音频」点「浏览」选音频文件，支持 .wav .mp3 .flac .ogg .m4a .aac。
3. 「输出 MIDI」路径一般自动填好，也可改。
4. 点「开始转换」，等 PianoTrans 跑完，生成的 MIDI 会自动进播放器；中途可「取消转换」。

例子：一首 3 分半的流行歌，在普通办公机上转谱大约花 1 到 2 分钟；人声突出、伴奏简单的音频认得更干净，弹出来更接近原曲。

---

## 9. 定时任务

进入「定时任务」页：

- 「校时状态」卡片点「测量 NTP」测一次网络时间偏移，结果写在「服务器与测量结果」里。
- 「执行时间」卡片填「日期」（日期选择器）、「时间」（格式 HH:mm 或 HH:mm:ss）、「MIDI 路径」（留空就用当前曲目），勾「使用最近一次 NTP 偏移」可校正时间，然后点「设置任务」；「取消任务」撤掉。
- 到点在指定时刻自动载入该 MIDI 并开始播放。

---

## 10. 键位与预设

进入「键位与预设」页，查看和编辑当前乐器下每个 MIDI 音符映射到的键盘键，把一套配置存成预设，方便给不同游戏切换。通用钢琴默认把 C3–B5 映射到 A S D F G H J Q W E R T Y U 1 2 3 4 5 6 7 等键。

---

## 11. 设置

- **外观与语言**：「切换主题」在浅色和深色之间切；「切换语言」在中英文之间切。品牌强调色是蓝色，浅色主题用 `#2F6BF5`、深色主题用 `#5B9BFF`，主题只有浅色和深色两种。
- **播放安全**：说明 SendInput 只向前台目标进程发键、失焦自动停，以及窗口消息后台模式的适用情况。
- **软件更新**：「检查更新」会去 GitHub 拉最新发布、下载安装包并拉起安装；「打开发布页」直接打开 Releases 页面。更新是手动点出来的，不会开机自检查。
- **关于**：显示版本号和简介「面向 Windows 的 MIDI 游戏乐器自动演奏工具」，作者薮猫。

- 播放 / 暂停：`Ctrl + Shift + C`
- 停止：`F9`

## 13. 常见问题

- **点播放没反应？** 确认「目标窗口」已绑定且游戏在前台（前台模拟按键模式），或已绑定窗口并切到窗口消息模式；若当前是普通权限，部分游戏需管理员权限才能稳定收键（程序启动时会自动请求提权，只有在 UAC 里取消后才会以普通权限运行）。
- **能后台弹吗？** 选「窗口消息（后台）」模式（游戏支持时）可以，前台模拟按键要求游戏在前台。
- **音频转谱失败？** 确认本机装了 PianoTrans，并在「音频转谱」页用「选择目录」指对它的位置。
- **更新失败？** 查网络或代理后重试「检查更新」，或直接去 Releases 下安装包。

## 14. 数据与隐私

设置、曲库索引、播放队列、预设、在线曲目收藏都存在 `C:\Users\你的用户名\AppData\Local\MeowField` 下，文件有 settings.json、presets.json、playlist.json、favorites.json、library.json 和 logs 目录。

需要排查问题时，进「日志与诊断」页点「导出诊断包」，会生成一个 zip（日志里的用户名、路径等已做脱敏），里面含日志和环境信息。
