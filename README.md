# MeowField_AutoPiano

**自动弹琴 · 音频转 MIDI 谱 · 《开放空间》PC 端乐器自动演奏**

MeowField_AutoPiano 是一款 Windows 自动弹琴软件：加载 MIDI 即可自动向目标窗口演奏，也能把普通音频文件自动转换为 MIDI 谱。软件专为《开放空间》PC 端乐器玩法适配，同时内置《异环》《第五人格》等游戏的乐器键位档案，开箱即用。

## 功能特性

- **自动弹琴**：加载 MIDI 后自动向游戏窗口发送按键，支持钢琴、架子鼓、麦克风模式
- **音频转 MIDI 谱**：WAV / MP3 / FLAC / OGG / M4A / AAC 音频一键转为 MIDI，转换完成直接载入播放
- **游戏乐器档案**：内置多款游戏乐器的键位、音域和演奏参数，一键切换，免手动配置
- **在线曲库**：进入页面自动拉取最新曲目，支持搜索、分类、大小、排序组合筛选，点击即载入播放，不写入本地磁盘
- **本地曲库**：扫描目录批量收录 MIDI，支持搜索、分页浏览和曲目管理
- **播放队列**：多曲目排队、自动连播、暂停继续、拖拽进度条
- **定时演奏**：按本地时间或 NTP 校时，在指定时刻自动开播
- **键位编辑器**：自定义 MIDI 音符到键盘按键的映射，可保存为参数预设
- **演奏参数**：速度、移调、最大复音、和弦处理、链路延迟补偿、自动移调等
- **双输入方式**：SendInput 前台输入与窗口消息后台输入，适配不同游戏窗口
- **界面体验**：粉色现代主题、浅色/深色模式、沉浸式无边框窗口、中英文界面、虚拟键盘预览、日志与诊断导出
- **自动更新**：内置在线检查更新，自动下载新版安装包并拉起安装

## 安装与更新

- 支持 Windows 10 / 11 64 位系统
- 从 GitHub Releases 下载 `MeowField_AutoPiano-*-win-x64-Setup.exe` 安装即可
- 安装包为自包含版本，普通用户**不需要**安装 .NET、Python 或 Node.js
- 部分游戏窗口需要管理员权限才能稳定发送按键，建议以管理员身份运行
- 在“设置”页点击“检查更新”，软件会自动下载新版安装包并拉起安装，无需手动替换文件

## 快速上手

1. 安装并启动 MeowField_AutoPiano。
2. 打开《开放空间》PC 端，进入乐器演奏界面。
3. 在“播放”页选择目标窗口并刷新绑定。
4. 打开本地 MIDI、从在线曲库选择曲目，或直接把 `.mid` / `.midi` 文件拖入窗口。
5. 选择游戏乐器档案或乐器（钢琴 / 架子鼓 / 麦克风）、输入方式和键位映射。
6. 点击播放，或使用全局快捷键开始演奏。

> 使用 SendInput 时，目标游戏窗口必须处于前台；窗口失去焦点后程序会自动停止发送，避免误操作其他程序。窗口消息模式适用于支持后台消息的游戏。

## 音频转 MIDI 谱

1. 在“音频转谱”页选择音频文件（WAV / MP3 / FLAC / OGG / M4A / AAC）。
2. 首次使用请在转换页指定本机 PianoTrans 所在目录（程序也会自动查找常见位置）。
3. 点击转换，等待 PianoTrans 完成识别。
4. 转换出的 MIDI 会自动载入播放器，可直接绑定窗口开始弹奏。

> 音频转谱需要本机安装 PianoTrans，转换耗时取决于音频长度和电脑性能。

## 在线曲库

- 进入“在线曲库”页面会自动拉取最新曲目索引
- 支持关键词搜索，以及分类、大小、排序组合筛选
- 点击“加载播放”即可把曲目载入播放器，曲目不写入本地磁盘，避免数据膨胀

## 常见问题

- **为什么点击播放没有反应？** 确认已在“播放”页绑定目标窗口且游戏窗口处于前台；部分游戏需要以管理员身份运行本软件。
- **能否后台播放？** 窗口消息模式可用于支持后台消息的游戏；SendInput 模式要求游戏窗口在前台。
- **音频转谱失败？** 确认本机已安装 PianoTrans，并在“音频转谱”页指定其安装目录。
- **更新失败？** 检查网络连接与代理设置后重试，或直接从 GitHub Releases 下载安装包。

## 数据与隐私

软件设置、曲库索引、播放列表和预设保存在 Windows 用户本地应用数据目录；在线曲库只读取不保存。日志可在“日志与诊断”页面导出诊断包。

## 从源码构建（开发者）

本仓库只提交源代码、测试和构建脚本，不包含 `bin/`、`obj/`、`artifacts/` 等编译产物。普通用户请直接使用 GitHub Releases 中的安装包。

```powershell
dotnet build MeowField.sln
dotnet test MeowField.sln --no-build
.\scripts\publish-win-x64.ps1
```

构建输出仅用于本地发布，不应提交到 GitHub。
